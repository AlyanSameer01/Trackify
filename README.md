# Trackify 💸

A powerful and intuitive Expense & Income Tracker built with **Flutter** and **Firebase**.

## 🚀 Features
* **Real-time Tracking:** Log expenses and income instantly.
* **Firebase Backend:** Secure data storage and sync across devices.
* **Clean UI:** Minimalist design for quick financial entries.

## 🛠️ Tech Stack
* **Frontend:** Flutter & Dart
* **Backend:** Firebase (Firestore / Auth)
* **State Management:** [Provider]
